# iCoach: Elevate Performance

Build the complete FRONTEND/UI/UX of a web platform called iCoach.

iCoach is a premium online fitness coaching platform where coaches manage clients, workouts, nutrition, schedules, progress, meetings and communication, while clients follow their plans, complete daily tasks, track progress and communicate with their coach.

MOST IMPORTANT PRIORITY

The biggest priority of this project is the visual experience and UI/UX quality.

I do NOT want iCoach to look like a typical AI-generated SaaS dashboard.

Do not create:

Generic dashboard layouts

Generic purple/blue AI gradients

Basic Tailwind-looking cards everywhere

Flat interfaces with no personality

Excessive rounded cards

Template-like layouts

Random gradients just to make the UI look modern

I want iCoach to feel like a real premium fitness technology brand.

Think:

Performance + Energy + Motion + Strength + Premium Technology

The interface should feel ALIVE.

When someone opens iCoach, they should immediately feel that this is a serious fitness/coaching product.

VISUAL IDENTITY

Create a strong dark visual identity.

Base colors should be:

TECHNICAL CONSTRAINTS

Frontend only.

Do NOT add:

Database

Supabase

Backend

API

Real authentication

Payment system

External integrations

Use local/mock data only for demonstration.

Create reusable TypeScript components and data models so the backend/database can be connected later.

Keep dependencies minimal.

Do not waste credits on unnecessary architecture.

FINAL QUALITY CHECK

Before finishing, review the entire application as a real product designer.

Ask:

"Does this look like a premium fitness product that a real company could launch?"

If any page looks like a generic AI-generated dashboard, redesign that page.

Make sure:

Visual identity is consistent

Red accent is used intelligently

Dark theme feels premium

Fitness imagery feels intentional

Animations are smooth

Interactions feel alive

Typography has personality

Layouts are not repetitive

Mobile UX is excellent

No broken routes

No empty unfinished pages

Coach and Client experiences feel different

The application feels fast and polished

The final result should feel like:

A premium fitness technology product + modern athletic brand + powerful SaaS platform.

NOT:

A generic AI-generated admin dashboard.

Focus on quality of visual design, motion, interaction and overall product feeling above adding unnecessary features.

